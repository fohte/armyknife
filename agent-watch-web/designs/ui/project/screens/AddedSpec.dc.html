追加分の仕様 (10〜17)

0 枚目「設計のまとめ」に足す内容。画面は 10〜17 を参照。

# Inbox の絞り込み (10・11)

  • Inbox の見出しの下に常に置く。/ で入る
  • 条件: project: kind: task: repo: engine: has:decision。メニューでも文字でも指定できる
  • 絞っても Needs action / Later / In progress / Done の区分と tq の優先度順はそのまま。件数だけ変わる
  • 条件はチップで出し × で外す。右に「3 of 6」
  • Save view で左のナビの VIEWS に残す。VIEWS には Needs action の件数を出す

# ⌘K (12・13)

  • どこからでも、セッション・tq タスク・プロジェクト・コマンドへ移動する
  • 空のとき: Needs action の上位 3 件、最近開いたもの、よく使うコマンド
  • 入力したとき: 種類ごとに分けて出す。セッションはタイトルとブランチ名で当たる。行には tq とリポジトリを添える
  • # @ > で tq タスク・プロジェクト・コマンドに絞る。Tab でも切り替え
  • ↵ 開く · ⌘↵ 会話の横に開く · → そのほかの操作
  • 絞り込み (/) は「いまの一覧を狭める」、⌘K は「別の場所へ飛ぶ」。役割を混ぜない

# セッションの状況欄と右のパネル (14・15)

  • タブは右のパネルの上に置く: Running · Tree · Decisions · crit。会話の側にはタブを置かない
  • 会話のヘッダーの右端にパネルの開閉ボタン (⌘.)。閉じているときも、動いている数 (◐ 4) をボタンに出す
  • パネルは 1 つだけで、閉じれば会話が広がる
  • 0 件の項目は出さない
  • Inbox の列は [ か、左のナビの一番上 (⌘K の横) の開閉ボタンで完全に畳む (帯も残さない)。戻すのも同じボタンか [。畳んでいる間はボタンを点灯させる。Needs action の件数はナビの Inbox に出ているのでそれで足りる。j / k は畳んだままでも次のセッションへ移る
  • 右のパネル (Running・Tree・crit など) を開くと Inbox は自動で畳み、パネルを閉じると元に戻す。手で開いたらその状態を優先する

# Subagent と background task (14)

  • Running タブには、いま動いているものだけを出す。終わったもの・失敗したものは出さない (Claude Code の TUI と同じ)
  • Subagent: 種類 (Explore など)、description、経過時間、ツールの回数、直近のツール呼び出し
  • Background task: コマンド、経過時間。Output と Stop
  • 会話の中にも開始した位置に枠つきの 1 行で出す。終わったらツールの実行の 1 行 (Task ×1 / Bash ×1) に畳む

# 親子の木 (15)

  • 右のパネルの Tree タブに、親子関係を木で出す。いちばん上の親から、子・孫まで
  • いま開いているセッションの行は明るい背景と左の白線。子を開いても同じ木が出て、自分の位置がわかる
  • 行は状態・タイトル・種類と最後の発言。tq とリポジトリは親と違うときだけ出す
  • 自分の祖先と子は開いた状態、それ以外の枝は畳む (▸)。← / → で開け閉め、j / k で移動、↵ で開く
  • Needs action の子孫がいれば Tree タブの件数を黄色にする。畳んだ枝の中にいる場合は、その枝の行にも件数を出す

# tq タスクが複数のセッション (16)

  • 1 つを primary にする。既定は優先度が一番高いもの。手で変えられる
  • Inbox・⌘K・Board の行には primary だけを出し、後ろに「+2」
  • 並び順と Board の列は primary で決める。絞り込みの task: はどれか 1 つに当たれば出す
  • 会話のヘッダーの「+2 tasks」で一覧を開き、primary の変更・追加・解除をする。変えたら armyknife event として会話に残す

# 会話に出るメッセージの種類 (17)

向き
右はこちらから出たもの: You (塗りの吹き出し) と Peer message の TO (点線の枠)。左は外から来たもの: エージェントの発言と Peer message の FROM (実線の枠と白い FROM の札)。
開けるもの (枠つき)
動いている Subagent・Background task と Peer message。押すと Running タブか相手のセッションを開く。peer message は札の横に相手のセッション名を必ず出す。
出来事 (文字だけの 1 行)
armyknife event (状態の変化・紐付け)、system event (compact・resume・モデル変更)、hook の出力。失敗やブロックだけ赤。

ツールの実行
出力やコマンドは解析しない。畳んだ 1 行は「Edit queue.rs, mod.rs · Read ×3 · Bash ×1」: ツール名と回数、ファイルを扱うツール (Read 以外の Edit / Write) だけ file_path のファイル名を最大 2 つ。失敗は tool_result の is_error の件数だけ赤で足す。開くと 1 回 1 行で「ツール名 · 主な引数を 1 行で省略 · ✓/×」。行を開くと入力と出力の末尾 20 行をそのまま出す。

セッション名
どこに出ても点線の下線つきリンク。hover で状態・tq・リポジトリのカード、クリックで開く。
