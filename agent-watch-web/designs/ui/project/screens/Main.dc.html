> agent watch

Claude Code / Codex のセッションを、この画面だけで捌く

普段は Inbox で「対応が必要なもの」を tq の優先度順に上から片付ける。全体は Board で見直す。会話も、crit のレビューも、ターミナルに戻らずにここで終える。

# 画面の構成

NavInbox会話crit / 判断
  • Nav: Inbox / Board の切り替え、VIEWS (保存した絞り込み)、TODAY (星を付けたもの)、PM (全プロジェクト分、畳まない)
  • 会話: transcript をチャットとして表示。pane に移らずに返信・承認できる
  • 横のパネル: crit の設計書、セッションの判断の一覧

# 状態は 4 つ

Needs action · 止まって、あなたを待っている
Later · 自分で後回しにした。時刻か新しい動きで戻る
In progress · AI が進めている。見なくてよい
✓Done · 終わった。確認して Archive する

「読むだけ」という区分は作らない。報告も、確認が要るなら Needs action (Review) に入る。

# 行に必ず出すもの

PR 2: 配信キューを実装8s
Question · 設定キーを追加してよいですか？
P1 #123通知機能の刷新◇ 1 decisionexample/web-app
  1. セッションのタイトル (armyknife の優先順位で決める)
  2. 何を求めているか (種類 + 最後の発言)
  3. tq の優先度・ID・タスク名、リポジトリ
  4. 仮置きの判断の件数

# 止まる理由 (Needs action)

QuestionAskUserQuestion などの質問 Approveコマンドやツールの実行許可 Plan計画の承認 Proposal案を並べて選んでもらう (armyknife に新設) Reviewcrit の設計書・PR・調査結果 Errorエラーで止まった Stopped理由を言わずに止まった。少ないほどよい

止まるときは必ずどれかの理由を付けて止まるよう、エージェントに求める。選択肢は会話の中で縦に並べる。

# 仮置きの判断 (◇ Decision)

  • 迷っても止まらずに進め、「何を選び、他に何を考え、なぜそうしたか」を残す (armyknife に新設)
  • 会話の中は 1 行。開くと理由と OK / Change
  • Inbox では Needs action に数えず、行に「◇ 2 decisions」とだけ出す
  • Done になったら「to review」と出して見返すきっかけにする
  • 見返すのはセッションの横のパネル。別の一覧は持たない

# Later (後回し)

  • L キーで後回し。In 1 hour / This evening / Tomorrow / Next week / Until it changes
  • どれを選んでも、セッションに新しい動きがあれば戻る
  • Inbox では 1 行に畳み、次に戻る時刻だけ出す
  • ずっと議論しているセッションは TODAY に星を付けて別枠で持つ

# 並び順

  • 各区分の中は tq の優先度順。同じなら待っている時間が長い順
  • tq のタスクがないものは同じ区分の最後
  • グループで見出しを作らない。まとまりは行のラベルで分かるようにする
  • 親子はツリーにしない。会話のヘッダーから親へ移る

# プロジェクトと Board

セッションは上から順に判定して、最初に当てはまったプロジェクトに入る。

  1. 手で移したもの
  2. 親と同じプロジェクト
  3. tq のタスクのプロジェクト
  4. 作業したリポジトリ (複数登録できる)

どれにも当てはまらなければ Unsorted。Board は列がプロジェクトで、対応が必要なプロジェクトほど左。動きのないプロジェクトは隠す。

# 見た目

  • ダークのみ。fohte.net Design System の配色・書体・角丸なし
  • UI の文言は英語。会話の本文はそのまま
  • 色の意味は 4 つだけ: 黄 = 対応が必要 / 赤 = エラー / 青 = 作業中 / 灰 = それ以外
  • 赤のアクセントは # 見出し・リンク・> の印だけ

# iPhone

  • Inbox と会話だけ。Board と pane への移動は出さない
  • Needs action の行は Mac と同じ情報を出す
  • 選択肢は 44px 以上のボタンで縦に並べる
  • Mac と繋がっていないときは最終更新の時刻を出す
